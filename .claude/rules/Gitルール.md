# Github利用に関するルール

## リモートブランチルール

- コミット&プッシュは自動で行ってOKです。
- プルリクエストはNGです。  

## Git 命名規則

- コミット・ブランチ作成時は以下の命名規則に従ってください。


| 種類 | 用途 |
| ---- | ---- |
| feature/ | 新機能追加 |
| fix/ | 不具合修正 |
| hotfix/ | 緊急修正（本番環境） |
| refactor/ | リファクタリング |
| docs/ | ドキュメント修正 |
| style/ | コードスタイル・デザイン修正 |
| chore/ | その他の微調整・環境設定 |
