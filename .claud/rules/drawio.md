# drowio作成規約

## オブジェクト制約

- テキスト量から高さを自動計算し、座標の衝突チェックを入れる。見た目のレイアウトは今の構成を維持したまま、次回以降の手直しを減らすため。
- mxGraphModel に defaultFontFamily="フォント名" を設定  
- すべてのテキスト要素の style に fontFamily=フォント名; を追加  
- フォントサイズは標準の1.5倍 (18px程度) を使用  
- 矢印とラベルは 20px 以上離す  
- 日本語テキストの width は十分に確保 (1文字あたり 30-40px)  
- page="0" を設定


## レイアウト構成
- キャンバスサイズ: 1600px x 900px
- 用紙の向き：縦長(potrait)
- フローは基本的に上から順に縦に並べるようにする。
- 条件分岐の場合はTrue CaseとFalse Caseを横に並べてよい
- テーブルやDBなど外部参照する場合は、横に並べてよい
