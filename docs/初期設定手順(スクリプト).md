# MimicVault 初期設定手順（スクリプト版）

スクリプトを使って、拡張機能の永続インストールと companion アプリ（スクリプト版）をセットアップする手順です。
companion アプリの exe 版（配布用、Node.js/FFmpeg 不要）は [初期設定手順(exe).md](初期設定手順(exe).md) を、
companion アプリ自体の仕様は [コンパニオンアプリ.md](コンパニオンアプリ.md) を参照してください。

---

## 1. 前提ツールの導入

拡張機能の永続インストールには **Firefox（ESR / Developer Edition）** と、XPI ビルドに使う **web-ext**
（Node.js / npm 経由で導入）が必要です。companion アプリ（スクリプト版）の実行には
**Node.js / npm** と **FFmpeg** も必要です。すでに導入済みの場合はこの章を飛ばしてください。

### 1.1 Firefox（ESR / Developer Edition）の導入

| Firefox 版 | 未署名拡張の永続インストール |
|---|---|
| **ESR** | ✅ 可 |
| **Developer Edition** | ✅ 可 |
| Release（通常版） | ❌ 不可 |

MimicVault は未署名（ID `mimicvault@local`）のため、通常版（Release）では動作しません。
ESR または Developer Edition を用意してください。

**ダウンロード**

- ESR: https://www.mozilla.org/firefox/enterprise/ の「Firefox ESR をダウンロード」から入手します。
- Developer Edition: https://www.mozilla.org/firefox/developer/ から入手します。

**インストール**

- **Windows**: ダウンロードした `.exe` を実行し、インストーラーの指示に従います。
- **macOS**: ダウンロードした `.dmg` を開き、Firefox アイコンを `Applications` フォルダへドラッグします。
- **Linux**: ダウンロードした `.tar.bz2` を展開し、中の `firefox` 実行ファイルを起動します
  （または各ディストリビューションが提供する ESR パッケージを使用してください）。

**未署名拡張を許可する設定（一度きり）**

1. アドレスバーに `about:config` と入力して Enter を押します。
2. 「リスクを承知の上で使用する」ボタンをクリックして警告画面を通過します。
3. 上部の検索欄に `xpinstall.signatures.required` と入力します。
4. 表示された項目の値（Boolean）をダブルクリックして `true` → `false` に切り替えます。

> この pref はセキュリティ設定のため、後述の enterprise policy では配布されません。必ず手動で設定してください。

### 1.2 Node.js / npm の導入

companion アプリ（スクリプト版）の実行ランタイムです。**v14 以上**が必要です。

- **Windows**:
  - 公式サイト https://nodejs.org/ から LTS 版のインストーラー（`.msi`）をダウンロードして実行、
    もしくは `winget install OpenJS.NodeJS.LTS` を実行します。
- **macOS**:
  - 公式サイトから `.pkg` をダウンロードして実行、もしくは [Homebrew](https://brew.sh/) で
    `brew install node` を実行します。
- **Linux（Ubuntu / Debian 系）**:
  - `sudo apt update && sudo apt install -y nodejs npm` で導入できますが、ディストリのリポジトリは
    バージョンが古い場合があります。最新 LTS が必要な場合は [nvm](https://github.com/nvm-sh/nvm) の利用を推奨します。
    ```bash
    curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
    # ターミナルを再起動、または `source ~/.bashrc` 実行後
    nvm install --lts
    ```

**確認**

```bash
node -v
npm -v
```

### 1.3 FFmpeg の導入

HLS→MP4 変換・DASH mux に使用します。**4.0 以上**が必要です。

- **Windows**:
  1. https://www.gyan.dev/ffmpeg/builds/ （または [BtbN のビルド](https://github.com/BtbN/FFmpeg-Builds/releases)）から
     `release full` 版の zip をダウンロードします。
  2. 任意の場所に展開します（例: `C:\ffmpeg`）。
  3. 「システムの詳細設定」→「環境変数」→ ユーザー環境変数（または システム環境変数）の `Path` を選択して「編集」。
  4. 「新規」から展開先の `bin` フォルダ（例 `C:\ffmpeg\bin`）を追加し、OK で保存します。
  5. 新しいコマンドプロンプトを開き直して反映させます。
- **macOS**:
  - [Homebrew](https://brew.sh/) を導入済みであれば `brew install ffmpeg` の一行で完了します。
- **Linux（Ubuntu / Debian 系）**:
  - `sudo apt update && sudo apt install -y ffmpeg`
  - Fedora 系は `sudo dnf install ffmpeg`（RPM Fusion リポジトリの有効化が必要な場合があります）。

**確認**

```bash
ffmpeg -version
```

### 1.4 web-ext の導入

拡張機能の lint / 開発起動 / XPI ビルドに使う Mozilla 公式 CLI です。`package.json` の
`devDependencies` に含まれているため、個別インストールは不要です。1.2 で Node.js / npm を
導入済みなら、リポジトリのルートで `npm install` するだけで同時に入ります。

1. ターミナル（Windows はコマンドプロンプトまたは PowerShell）を開きます。
2. `cd` でリポジトリのルート（`package.json` や `manifest.json` があるフォルダ）へ移動します。
   ```bash
   cd /path/to/MimicVault
   ```
3. `npm install` を実行します。`package.json` の `devDependencies` に書かれたツール（`web-ext` など）を
   自動でダウンロードし、同じフォルダ内の `node_modules` に格納します。
   ```bash
   npm install
   ```

> **Windows**: 上記 1〜3 の代わりに、リポジトリのルートにある `setup.bat` をダブルクリックするだけでも
> 同じ `npm install` を実行できます（内部で `cd` → `npm install` を行うだけの薄いラッパーです）。

**確認**

`npx` は `node_modules` にインストールされたコマンドを直接実行する仕組みです（PATH設定は不要）。

```bash
npx web-ext --version
```

バージョン番号（例 `8.10.0`）が表示されれば導入完了です。

> `npm run lint` / `npm run run` / `npm run build` が内部で `web-ext` を呼び出します
> （共通設定は `web-ext-config.mjs`）。

## 2. 拡張機能の永続インストール（enterprise policy）

Firefox の **enterprise policy**（`ExtensionSettings` → `force_installed`）を使い、未署名の
MimicVault 拡張機能を「企業ポリシーにより追加」として永続的に常駐させる手順です。
`web-ext run` の一時読み込みと違い、**Firefox を再起動しても消えません**。

### 2.1 前提

- 1.4 で web-ext を導入済みであること（`npm install` 済み。XPI ビルドに使用）

### 2.2 インストール実行

インストーラが以下を自動で行います。

1. `web-ext build` で XPI をビルド
2. XPI を安定パスへ配置
   - macOS / Linux: `~/.mimicvault/mimicvault.xpi`
   - Windows: `%APPDATA%\MimicVault\mimicvault.xpi`
3. `deploy/policies.json` のプレースホルダ `__XPI_PATH__` を実パスに置換し、
   Firefox の policies ディレクトリへ配置（永続追加 + プライベートウィンドウ許可）

**macOS / Linux**

```bash
./deploy/install-policy.sh [<policies ディレクトリ>]
```

- 第1引数を省略すると配置先を自動選択します。
  - **Linux**: `/etc/firefox/policies`（システム全体。書き込みに **sudo** が必要な場合あり）
  - **macOS**: `/Applications/Firefox Developer Edition.app/Contents/Resources/distribution`
- 別の Firefox を使う場合は第1引数でディレクトリを指定します。

```bash
# 例: 自分のプロファイル用 distribution に配置
./deploy/install-policy.sh ~/firefox-deved/distribution
```

**Windows**

```bat
:: 省略可（Developer Edition の既定パスを使用）
deploy\install-policy.bat

:: 別の Firefox を使う場合は実パスを指定（角括弧・山括弧は付けない）
deploy\install-policy.bat "C:\Program Files\Firefox Developer Edition\distribution"
```

- 第1引数を省略すると `C:\Program Files\Firefox Developer Edition\distribution` を既定にします。
- policies.json の書き込みに**管理者権限が必要な場合があります**。

### 2.3 反映と確認

1. **Firefox を再起動**します。
2. `about:addons` に MimicVault が **「企業ポリシーにより追加」** として表示されれば成功です。
3. `about:policies` でも配置内容を確認できます。

### 2.4 配布される設定内容

`deploy/policies.json`（配置時に `__XPI_PATH__` が実パスに置換されます）:

```json
{
  "policies": {
    "ExtensionSettings": {
      "mimicvault@local": {
        "installation_mode": "force_installed",
        "install_url": "file://__XPI_PATH__"
      }
    },
    "Preferences": {
      "extensions.allowPrivateBrowsingByDefault": { "Value": true, "Status": "locked" }
    }
  }
}
```

- `force_installed`: 拡張を永続追加（ユーザーによる削除も禁止）
- `allowPrivateBrowsingByDefault=true`: プライベートウィンドウでの実行を全体許可
  （`webRequest` でメディア検出するために必要）

### 2.5 アップデート手順

拡張のコードを更新したら、**インストールと同じコマンドを再実行**するだけです。
新しい XPI が同じパスに上書き配置され、Firefox 再起動で反映されます。

```bash
# macOS / Linux
./deploy/install-policy.sh [<policies ディレクトリ>]

# Windows
deploy\install-policy.bat ["<Firefox>\distribution"]
```

### 2.6 アンインストール

1. 配置した `policies.json` を削除します（配置先はインストール時のログに表示されます）。
   - 例（Linux 既定）: `/etc/firefox/policies/policies.json`
   - 例（Windows 既定）: `C:\Program Files\Firefox Developer Edition\distribution\policies.json`
2. Firefox を再起動すると `about:addons` から MimicVault が消えます。
3. 配置済み XPI が不要なら削除します。
   - macOS / Linux: `~/.mimicvault/`
   - Windows: `%APPDATA%\MimicVault\`

> companion アプリ（Native Messaging / FFmpeg）のインストール・アンインストールは次章、
> および [コンパニオンアプリ.md](コンパニオンアプリ.md) を参照してください。拡張機能とは別管理です。

### 2.7 トラブルシューティング

| 症状 | 原因 / 対処 |
|---|---|
| `about:addons` に出ない | `about:policies` で policy が読まれているか確認。Firefox を完全再起動したか確認。 |
| 「署名されていないため無効」 | `xpinstall.signatures.required=false` が未設定。1.1 節の手順を実施（ESR / Developer Edition のみ有効）。 |
| Release 版で入らない | 仕様。Release は未署名を拒否。ESR / Developer Edition を使用。 |
| `web-ext-artifacts/*.zip が見つかりません` | ビルド失敗。ルートで `npm install` 後、`npm run build` が通るか確認。 |
| policies.json を書き込めない | 配置先が権限不足。Linux は `sudo`、Windows は管理者権限で実行、またはプロファイル用 `distribution` を第1引数で指定。 |
| プライベートウィンドウで検出しない | policy 未反映。再起動後、`about:addons` →「プライベートウィンドウでの実行を許可する」を手動確認。 |

## 3. companion アプリ（スクリプト版）のインストール

スクリプト版（開発・自分用）は `node app.js` を .bat/.sh ラッパー経由で実行します。1章で Node.js / FFmpeg を
導入済みであることが前提です。

### macOS

```bash
cd companion/
chmod +x install.sh mimic-vault
./install.sh
```

### Windows

`install.bat` をダブルクリック（または cmd.exe から実行）

管理者権限は**不要**です（レジストリは `HKCU` に書き込みます）。

インストール後、Firefox を再起動すると拡張機能のポップアップ右上に companion 接続インジケータが表示されます。
詳細は [コンパニオンアプリ.md](コンパニオンアプリ.md) を参照してください。
